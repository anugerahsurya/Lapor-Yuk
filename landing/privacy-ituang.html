Kebijakan Privasi

Diperbarui 15 November 2026.

Data hanya di perangkat

Rekening, transaksi, anggaran, celengan, impian, catatan, dan nama panggilan disimpan di penyimpanan HP-mu sendiri. Pencatatan dan laporan bekerja offline. Saat kamu menekan Cek update, aplikasi mengambil informasi versi publik dari GitHub. Data keuangan tidak dikirim. Saat kamu memilih Unduh versi terbaru, tautan APK dibuka di browser. GitHub atau penyedia unduhan dapat menerima informasi koneksi seperti alamat IP sesuai kebijakan layanan mereka.

Kamera & galeri

Kamera atau galeri hanya dipakai bila kamu menambahkan foto pada impian. Foto dikecilkan lalu disimpan di folder aplikasi.

Backup

File backup (.json) dan rekap PDF hanya dibuat saat kamu memintanya, lalu kamu sendiri yang memilih tempat menyimpan atau membagikannya.

Menghapus data

Uninstall aplikasi atau hapus data aplikasi akan menghapus semua catatan. Lakukan backup berkala bila ingin menyimpannya.
